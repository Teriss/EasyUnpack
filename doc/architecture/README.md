# Architecture

This directory records durable design decisions for EasyUnpack.

- `engine-adapters.md` will define external extraction-tool contracts.
- `shell-extension.md` will document the Windows Explorer integration boundary.
- `password-vault.md` documents password persistence and protection behavior.
- `output-publication.md` documents output naming, redundant-directory normalization, and publication guarantees.
- `progress-reporting.md` documents the observable extraction activity boundary and why unknown archive totals use an indeterminate indicator.
